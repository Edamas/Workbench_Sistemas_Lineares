### 1. Exercícios Práticos

**P.1** Resolva os seguintes sistema lineares, utilizando o método de escalonamento:

(a) `S = { 2x + y = 5, x - 3y = 6 }`
(b) `S = { √3x - iy = 0, x - y = -3 + i√3 }`
(c) `S = { x - 2y + 3z = 0, 2x + 5y + 6z = 0 }`
(d) `S = { 2x - y + 3z = 11, 4x - 3y + 2z = 0, x + y + z = 6, 3x + y + z = 4 }`
(e) `S = { ix + z = 2i, 2x - iz = 4, -ix + z = -i }`
(f) `S = { y + 3z = -2, 2x + y - 4z = 3, 2x + 3y + 2z = -1 }`
(g) `S = { x - 2y + 3z = 0, 2x - y + 2z = 0, 3x + y + 2z = 0 }`
(h) `S = { 3x + 5y = 1, 2x + z = 3, 5x + y - z = 0 }`
(i) `S = { x₁ + 3x₂ + 2x₃ + 3x₄ - 7x₅ = 14, 2x₁ + 6x₂ + x₃ - 2x₄ + 5x₅ = -2, x₁ + 3x₂ - x₃ + 2x₅ = -1 }`
(j) `S = { x - 3y + z = 2, -2x + 3y - 3z = -1, 2x - 9y + z = 5 }`
(k) `S = { x + 3y - 2z = 4 - 4i, -ix + 2y + z = 8, x + y - z = 1 }`
(l) `S = { 2x - i√2y = 0, ix + y = 0 }`
(m) `S = { x + y + z = 4, 2x + 5y - 2z = 3 }`
(n) `S = { x + y + z = 4, 2x + 5y - 2z = 3, x + 7y - 7z = 5 }`
(o) `S = { 2y + 2z = 0, x + y + 3z = 0, 3x - 4y + 2z = 0, 2x - 3y + z = 0 }`
(p) `S = { x + y + z + w = 0, x + y + z - w = 4, x + y - z + w = -4, x - y + z + w = 2 }`
(q) `S = { -2x + y + 5z = 0, x - 2y - 4z = -3i, x - y - 3z = -i }`

**P.2** Determine `k` para que o sistema abaixo admita solução (e exiba a solução):
`S = { -4x + 3y = 2, 5x - 4y = 0, 2x - y = k }`

**P.3** Determine `k` para que o sistema homogêneo abaixo admita solução não trivial (e exiba-a):
`S = { 2x - 5y + 2z = 0, x + y + z = 0, 2x + kz = 0 }`

**P.4** Descreva todas as possíveis matrizes 2x2, 2x3 e 3x3 que estão na forma escalonada (ou linha-reduzida à forma escada).

**P.5** Discuta a solução do seguinte sistema linear:
`{ 3x + 5y + 12z - w = -3, x + y + 4z - w = -6, 2y + 2z + w = 5 }`
(a) Acrescente a equação `2z + kw = 9` a este sistema e encontre um valor de `k` que torne o sistema impossível.

**P.6** Determine os valores de `k` (se houver) de modo que o sistema abaixo tenha:
(a) Solução única.
(b) Infinitas soluções.
(c) Nenhuma solução.
`{ x + y + kz = 2, 3x + 4y + 2z = k, 2x + 3y - z = 1 }`
